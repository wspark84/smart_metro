# 집에서 첫 탑승 지점까지 이동시간

- 홈의 `집 → 첫 정류장·역 이동시간 (분)`에 직접 입력합니다. 0~180 사이 정수, 빈 값은 미설정입니다.
- `교통편 도착까지 남은 시간 - 입력한 이동시간 = 집에서 출발까지 남은 시간`입니다.
- 예: 버스 10분 후 도착, 이동시간 5분 → 5분 안에 출발.
- 마을버스로 시작할 때 약 3분 여유를 더해 입력하도록 권장합니다. 자동으로 더하지 않습니다.
- 0분이면 지금 출발, 음수면 출발 기한 경과/탑승 어려움으로 표시합니다. 초 단위 잔여시간은 내림하여 과도한 여유를 주지 않습니다.
- 버스/지하철 모두 같은 규칙입니다. 목적지 예상 도착시간에 이동시간을 다시 더하지 않습니다.
- 계정 경로 정보 `boardingAccessMin`으로 저장합니다. 과거 자동 추정값 `homeToStopWalkMin`은 사용자 입력으로 취급하지 않습니다.
- 홈과 서버 알림, 푸시 본문, 한국어 음성 안내가 같은 계산 결과를 사용합니다.
- 목적지 경로 또는 실시간 정보가 없으면 마지막 정시 교통편/출발 시각을 임의로 만들지 않습니다.
- 기존 사용자가 값을 입력하지 않았다면 기존 교통편 도착 카운트다운을 유지합니다.
