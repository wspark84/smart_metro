## C. 구글플레이 제출 시 입력 항목
- 앱 이름: 이노치 - 이거 놓치면 지각 / 카테고리: 지도 및 내비게이션(또는 여행 및 지역정보)
- 개인정보처리방침 URL: `https://smart-metro.vercel.app/privacy`
- 계정 삭제 URL: `https://smart-metro.vercel.app/account/delete`
- 데이터 보안 양식: 이메일·이름(계정), 대략적 위치 아님(사용자가 입력한 주소·좌표 = "기타 위치 정보 / 사용자 제공"), 앱 활동, 기기 ID(푸시 토큰), 구매 내역 · 전송 중 암호화 예 · 삭제 요청 가능 예
- **전체 화면 알림(USE_FULL_SCREEN_INTENT) 신고**: 앱 콘텐츠 → "알람" 핵심 기능으로 신고
- 정확한 알람(SCHEDULE_EXACT_ALARM): 사용자가 설정에서 허용하는 방식 (앱의 설정 탭에서 안내)
- 콘텐츠 등급 설문, 타겟 연령(만 14세 이상), 광고 없음
- 구독 상품 `inochi_schedule_monthly` (월 5,000원, 기본 요금제 `monthly`) 등록 → 라이선스 테스터로 결제 시험 → 그 후 `INOCHI_BILLING_ENABLED=true`
- 내부 테스트 트랙으로 먼저 업로드 → 실제 휴대폰에서 로그인·설정·알림·탈퇴 확인 → 프로덕션 출시

## D. 결정이 필요한 사항
- **앱 ID** `com.buswakeup.buswakeup_mobile`은 첫 업로드 후 영구히 바꿀 수 없음. 사용자에게는 거의 보이지 않으므로 유지 권장(바꾸면 Firebase·카카오·구글 로그인 설정을 모두 다시 해야 함)
- **서버 주소** `smart-metro.vercel.app`: 출시 전 자체 도메인(예: inochi.app) 연결 권장. 바꾸면 로그인 복귀 주소·앱 설정을 함께 바꿔야 하므로 출시 전에 결정
