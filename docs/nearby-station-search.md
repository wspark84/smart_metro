# 지도 주변 정류장 검색

이름 또는 안내판 번호 검색에서 빠지는 정류장을 위치로 다시 찾는 보완 기능입니다.
홈 → 출발지 변경 → 버스에서 사용할 수 있습니다. TAGO 연결이 설정되어 있어야 합니다.

1. `지도 위치로 찾기`에서 근처 아파트·건물·주소를 검색합니다.
2. 검색 결과의 `이 위치로 지도 이동`을 누릅니다. 이 단계에서는 저장된 출발지가 변경되지 않습니다.
3. 지도를 움직여 중앙 `+`를 원하는 위치에 맞춥니다.
4. `이 위치 주변 정류장 찾기 · 500m`를 누릅니다.
5. 번호가 붙은 지도 핀 또는 정류장 목록을 선택하고, 도로 어느 쪽인지와 노선을 확인한 뒤 확정합니다.

지도 배경에 기본으로 그려진 작은 버스 아이콘은 선택 대상이 아닙니다.
주변 검색은 지도 이동 때 자동 호출하지 않습니다. 지도를 옮긴 뒤 버튼을 다시 눌러야 합니다.

## 데이터와 설정

- 기존 `TAGO_SERVICE_KEY`를 사용하며 별도의 환경변수는 없습니다.
- TAGO 버스정류소정보의 `getCrdntPrxmtSttnList` 상세기능 사용 권한이 필요합니다.
- 카카오 지도 표시 및 장소 검색은 기존 카카오 JavaScript/로컬 REST 키를 사용합니다.
- [공식 TAGO 버스정류소정보 안내](https://www.data.go.kr/data/15098534/openapi.do): GPS 좌표 기준 반경 500m 조회.
- 결과마다 API가 반환한 도시코드와 정류장 고유번호를 유지해 노선·도착정보를 조회합니다. 화면의 다른 도시 선택값으로 대체하지 않습니다.
- 공식 데이터에서 누락된 정류장까지 만들어낼 수는 없습니다. 결과가 비어 있거나 권한 오류가 발생하면 화면에 안내합니다.
- 새 조회 API는 로그인이 필요하며, 계정 저장·알람 처리 대기열과 분리되어 있습니다.
- 동일 위치의 결과는 5분 캐시합니다. 검색 위치를 별도 진단 로그에 기록하지 않습니다.

## 검증 범위

자동 시험은 공식 API 형식의 모의 응답으로 좌표, 페이지 처리, 도시 경계, 반대편 정류장 분리, 기존 출발지 보존, 오래된 검색 응답 무시, 로그인 필요 여부를 검증합니다.
실제 `04413` 정류장의 제공 여부와 운영 계정의 GPS 조회 권한은 운영 배포 후 직접 확인해야 합니다.
