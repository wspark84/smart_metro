# 도시 기준 버스 통합 검색

## 사용자 화면

- 홈 출발지에서 `버스 정보 지역` 제공기관 선택을 제거했습니다.
- 로그인 후 도시 목록을 자동 요청합니다. 로그인 완료 자체는 도시 요청을 기다리지 않습니다.
- 긴 드롭다운 대신 `도시를 검색하세요` 입력창을 사용합니다. `수원` 입력 시 `경기도 수원시` 추천 버튼을 클릭하거나, 결과가 하나면 Enter로 선택합니다.
- 빈 검색어에는 전체 목록을 펼치지 않습니다. 추천은 최대 8개이며 한글 입력 중 입력창을 교체하지 않습니다.
- 검색어를 수정하면 이전 도시 선택과 임시 정류장 결과만 해제하며 저장된 알람 경로는 바꾸지 않습니다.
- 도시를 선택하고 정류장 이름 또는 번호를 검색하면 사용 가능한 공식 정보를 한 목록으로 보여줍니다.
- 서울은 서울 API, 경기는 경기 API를 연결하고, TAGO 도시코드가 존재하면 TAGO도 함께 조회합니다.
- 서울·경기 시군 명칭은 내장 목록, 다른 도시와 TAGO 도시코드는 공식 도시 목록 API를 사용합니다. 서울·경기 전용 연결이 없는 도시는 TAGO 지원 여부에 따라 활성화됩니다.
- API 키가 없거나 도시 목록을 못 불러온 상황은 연결 준비 중/재시도 안내로 구분합니다.
- 동일 정류장이 기관별로 중복 제공될 수 있습니다. 검색 결과의 제공처 표기를 유지하며, 다른 기관의 고유번호를 임의로 합치지 않습니다.
- 경기 검색은 `regionName`이 선택한 시군과 일치하는 정류장만 포함합니다.
- 도시를 바꿔도 저장된 알람의 탑승 지점은 바뀌지 않습니다. 지도·노선 확인 후 확정할 때만 변경됩니다.
- 상세 설정의 제공처별 진단 기능은 기존대로 유지합니다.

## 운영자가 추가할 설정

2026-09-20 운영 공개 설정 확인 시 서울·경기 전용 키는 미등록이고 TAGO 키만 등록되어 있었습니다.
공공데이터포털에서 아래 API 활용신청과 상세기능 승인이 필요합니다.

| 정보 | 활용신청 | Vercel 환경변수 |
|---|---|---|
| 서울 정류장 검색·경유노선 | 서울특별시_정류소정보조회 서비스 | `SEOUL_OPEN_API_KEY` |
| 서울 도착정보 | 서울특별시_버스도착정보조회 서비스 | 위와 동일한 승인된 공공데이터포털 인증키 |
| 경기 정류장 검색·경유노선 | 경기도_버스정류소 조회 | `GYEONGGI_SERVICE_KEY` |
| 경기 도착정보 | 경기도_버스도착정보 조회 | 위와 동일한 승인된 공공데이터포털 인증키 |

Vercel → smart-metro → Environment Variables에서 두 변수를 **Secret / Production**으로 등록합니다.
공공데이터포털의 **일반 인증키(Decoding)** 값을 사용합니다. 서버가 URL 인코딩을 처리합니다.
키 값이 TAGO와 같더라도 서비스별 이용 승인은 별개이며, 이 앱의 두 환경변수에도 각각 등록해야 합니다.
`SEOUL_OPEN_API_KEY`는 서울 열린데이터광장 지하철 키(`SEOUL_SUBWAY_API_KEY`)가 아닙니다.
등록 뒤 재배포하고 서울/수원 정류장 → 노선 → 도착정보까지 운영 연결을 확인해야 합니다.
키는 채팅이나 Git에 남기지 않습니다.

## 검증

모의 공식 응답으로 도시 매핑, 같은 번호의 기관별 분리, 부분 장애, 빈 결과, 키 누락,
도시 자동 로딩·중복 요청 방지, 검색 중 로그아웃, 정류장 선택 전 기존 경로 보존,
확정 후 해당 제공기관으로 노선·도착정보 연결을 자동시험합니다.
실제 서울·경기 조회 성공은 전용 키 등록과 운영 배포 후에 확인할 수 있습니다.
